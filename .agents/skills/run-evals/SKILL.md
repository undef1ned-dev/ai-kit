Прогони эвалы AIKit скриптом `scripts/run-evals.py` из корня репозитория кита.

## 1. Что гонять

Эвалы разбиты на группы: `core` (ядро: скиллы base, хуки) и по группе на профиль (`vue-nuxt`, `python-fastapi`, `python-django`). Список групп и объём прогона покажет `python3 scripts/run-evals.py --list`.

- Пользователь назвал группу — гоняй только её: `python3 scripts/run-evals.py vue-nuxt`. Несколько групп — через пробел, `all` — все.
- Попросил «то, что поменялось» — `--changed`: раннер найдёт группы, затронутые изменениями ветки и незакоммиченными правками.
- Группу не назвал — выполни `python3 scripts/run-evals.py --changed --list` и спроси: затронутые группы (рекомендуй их), конкретный профиль или все. Уточни режим: `--quick` (один прогон) или полный. Runtime для Codex по умолчанию — `--runtime codex`, оба — `--runtime both`.

## 2. Подтверждение

Покажи состав и объём: `python3 scripts/run-evals.py <группы> --list` с теми же фильтрами. Объём — в долларах по прайсу API Claude: для подписки это мера расхода лимитов, а не деньги. Дождись согласия.

## 3. Прогон и итог

Запусти `python3 scripts/run-evals.py <группы> <флаги>` и дождись завершения. Итог: таблица кейсов с оценками и проваленными оценщиками, сколько ушло лимитов Claude (строка «Лимиты подписки» в выводе), путь к `evals/results/<время>/`, что поправить в агентах и скиллах — предложи, но не меняй без согласия.

Не запускай эвалы сам по себе — только когда пользователь явно попросил.
