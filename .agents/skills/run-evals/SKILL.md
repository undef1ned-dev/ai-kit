Прогони эвалы AIKit скриптом `scripts/run-evals.py` из корня репозитория кита.

## 1. Что гонять

Эвалы разбиты на группы: `core` (ядро: скиллы base, хуки) и по группе на профиль (сейчас `vue-nuxt`). Список групп и объём прогона покажет `python3 scripts/run-evals.py --list`.

- Пользователь назвал группу — гоняй только её: `python3 scripts/run-evals.py vue-nuxt --runtime codex`. Несколько групп — через пробел, `all` — все. Во всех командах передавай `--runtime codex`, если пользователь не выбрал другой runtime; CLI по умолчанию использует Claude.
- Попросил «то, что поменялось» — `--changed`: раннер найдёт группы, затронутые изменениями ветки и незакоммиченными правками.
- Группу не назвал — выполни `python3 scripts/run-evals.py --changed --list` и спроси: затронутые группы (рекомендуй их), конкретный профиль или все. Уточни режим: `--quick` (один прогон) или полный. Runtime для Codex по умолчанию — `--runtime codex`, оба — `--runtime both`.

## 2. Подтверждение

Покажи состав и объём: `python3 scripts/run-evals.py <группы> --list` с теми же фильтрами. Объём — в долларах по прайсу API Claude: для подписки это мера расхода лимитов, а не деньги. Дождись согласия.

## 3. Прогон и итог

Запусти `python3 scripts/run-evals.py <группы> --runtime codex <флаги>` с выбранным runtime и дождись завершения. Итог: таблица кейсов с оценками и проваленными оценщиками, фактическая статистика выбранного runtime из отчёта, путь к `evals/results/<время>/`, предложения по исправлениям. Если расход Codex не измерен, так и скажи; оценку API Claude не представляй как фактический расход Codex. Правки — только после согласия.

Не запускай эвалы сам по себе — только когда пользователь явно попросил.
