Проверь модели агентов AIKit в репозитории кита.

Runtime проверки возьми из сообщения пользователя.

## 1. Что есть сейчас

1. Прочитай `adapters/models.json`: уровни (`tiers`), модели каждого runtime, дату прошлой проверки (`checked`) и источники (`sources`).
2. Для Codex прочитай реальные `model` и `model_reasoning_effort` в `<слой>/codex/agents/*.toml` и `templates/profile/codex/agents/*.toml`. Это независимые defaults, они не вычисляются из уровней Claude. Проверь также `.codex/agents/aikit-maintainer.toml`. Для Claude/OpenCode прочитай уровни в Markdown и карту `adapters/models.json`. Запусти `python3 scripts/ci/test-agent-models.py`.

Аргумент — runtime: проверяй только его. Нет аргумента — все три.

## 2. Сверь с документацией

Для каждого runtime открой источник из `sources` доступным веб-инструментом и используй только официальную документацию:
- **Claude Code** — допустимые значения `model` у агентов. Алиасы `opus`, `sonnet`, `haiku` сами указывают на последнюю версию семейства: проверь, что они по-прежнему поддерживаются, и не появилось ли новое семейство, которое стоит взять в уровни.
- **Codex** — актуальные модели, какая рекомендуется по умолчанию, самая сильная и самая быстрая, что выводится из эксплуатации и когда; допустимые `model_reasoning_effort`.
- **OpenCode** — формат `provider/model` и актуальные id моделей Anthropic у провайдера `anthropic`.

## 3. Отчёт и правки

Покажи таблицу: runtime, агент/уровень, модель сейчас, актуальная модель, что не так, источник. Для Codex предложи изменения независимых TOML, а для совместимых tier override — `adapters/models.json`. Не меняй модели без согласия.

После согласия:
1. Поправь согласованные нативные TOML и/или `adapters/models.json`, поставь дату проверки в `checked`. Пересобери каталог сайта.
2. Прогони `PYTHONIOENCODING=utf-8 bash scripts/ci/run-all.sh`.
3. Закоммить по `git-commit` (например `build(models): обновлены модели Codex`): режим из `.aikit/settings.json` — `ask` — предложи 2–3 варианта и дождись выбора, `auto` — коммить сразу.

Не запускай проверку сама по себе — только когда пользователь вызвал этот скилл.
