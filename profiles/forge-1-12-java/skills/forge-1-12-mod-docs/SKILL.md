Запусти агента `forge-1-12-java-doc-writer` для документации мода.

$ARGUMENTS

Режим передай агенту:
- `--full` — документация по всему моду с нуля (или полная пересборка);
- `--check` — сверить `docs/` с кодом и исправить расхождения;
- раздел или фича (`блоки`, `конфиг`, `дробилка`) — обновить только затронутые страницы;
- без аргументов — если в разговоре есть CODER_RESULT или ARCHITECT_PLAN, обнови документацию по ним; иначе, если папки `docs/` нет, — с нуля; иначе спроси, что обновить.

Передай агенту CODER_RESULT и ARCHITECT_PLAN из разговора, если они есть, и папку `root` профиля `forge-1-12-java` из `.aikit/profiles.json`.

## После агента

1. Покажи пользователю DOCS_RESULT: какие страницы созданы и изменены
2. Если в QUESTIONS есть вопросы — задай их пользователю; после ответов запусти агента ещё раз с ответами (не больше одного лишнего круга)
3. Агент меняет только `docs/`. Если он изменил что-то вне `docs/` — скажи об этом пользователю
