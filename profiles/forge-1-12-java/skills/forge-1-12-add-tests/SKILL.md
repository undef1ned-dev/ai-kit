Запусти агента `forge-1-12-java-tester` для написания тестов.

$ARGUMENTS

Если не сказано, что тестировать, — спроси, какие классы или пакет.

Агент должен:
1. Прочитать классы и существующие тесты в `src/test/java/`
2. Определить сценарии: основной, ошибки, граничные значения; для пакетов — отказ при неверных данных
3. Написать тесты JUnit 4 (или JUnit 5, если он уже настроен в `build.gradle`) без новых зависимостей
4. Запустить команду `test` профиля из `.aikit/profiles.json` в папке `root` профиля и приложить результат

Если логика зашита в класс блока или TileEntity и без мира её не проверить — агент отмечает это в GAPS. Предложи пользователю вынести логику в `domain/` отдельной задачей.

Поведение в мире (рендер, GUI, синхронизация, выделенный сервер) unit-тестом не проверить: покажи ручной сценарий из IN_GAME_SCENARIO и предложи `/check-feature`.
