Добавь параметры конфига по правилам `CLAUDE.md` профиля `forge-1-12-java`.

$ARGUMENTS

Если не сказано, какие параметры, их тип, значение по умолчанию и диапазон, — уточни.

## Перед созданием

- Папка мода — `root` профиля `forge-1-12-java` в `.aikit/profiles.json`
- Найди `config/ModConfig` и как мод читает параметры сейчас. Если мод использует старый `Configuration` — не переписывай его, добавь параметры в том же стиле и предложи переход на `@Config` отдельной задачей

## Что сделать

1. `config/ModConfig.java` — `@Config(modid = MOD_ID)`, вложенные статические классы-категории для групп параметров
2. Каждый параметр:
   - `@Config.Comment` — что делает и на что влияет
   - `@Config.RangeInt` / `@Config.RangeDouble` для чисел; значение по умолчанию — внутри диапазона
   - `@Config.LangKey` и ключ в `assets/<modid>/lang/en_us.lang`
   - `@Config.RequiresMcRestart` или `RequiresWorldRestart`, если параметр читается только при старте
3. Синхронизация — подписчик `ConfigChangedEvent.OnConfigChangedEvent` с `ConfigManager.sync(MOD_ID, Config.Type.INSTANCE)`
4. Код читает параметры из `ModConfig`; в domain передавай значения через конструктор или параметры, а не читай статический конфиг изнутри domain — так логику можно тестировать

Параметры, которые меняют серверную логику, действуют на сервере; клиенту они не доверяются.

## После создания

1. Запусти `lint` профиля из `.aikit/profiles.json` в папке `root` и исправь ошибки
2. Покажи таблицу: параметр, по умолчанию, диапазон, нужен ли перезапуск
3. Предложи обновить документацию: `/forge-1-12-mod-docs конфиг`
