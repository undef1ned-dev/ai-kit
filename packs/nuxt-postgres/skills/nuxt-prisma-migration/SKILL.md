Подготовь изменение схемы и миграцию для указанной задачи.

1. Найди корень `vue-nuxt` в `.aikit/profiles.json`. Изучи версии Nuxt и Prisma, зависимости, lockfile, скрипты проекта, конфигурацию Prisma, схему и историю миграций. Путь схемы и миграций возьми из проекта. Если Prisma с PostgreSQL ещё не настроены, опиши, чего не хватает для миграции.
2. Сохрани совместимость с существующими данными. Для нового обязательного поля, уникальности или изменения типа проверь, как подготовить старые строки и в каком порядке выкатывать изменение. Для обновления связанных записей учитывай транзакции и повторные запросы.
3. Обнови схему и подготовь новую миграцию по правилам и версии Prisma проекта. Для генерации, которая подключается к БД, используй выделенную локальную или тестовую БД. Проверь сгенерированный SQL, включая изменения данных, ограничения и удаление столбцов. Уже применённые миграции оставь в истории в исходном виде.
4. Используй команды проекта и его пакетный менеджер. Применяй миграцию в выделенной локальной или тестовой БД, если это входит в запрос. Для остальных окружений опиши порядок применения. Проверяй схему и генерацию клиента командами проекта без вывода секретов.
5. В ответе укажи файлы, порядок выката, влияние на существующие данные и фактически выполненные проверки.
