Claude Code is the primary production path.

## Install

```bash
git submodule add git@github.com:undef1ned-dev/ai-kit.git .aikit-config
git submodule update --init
bash .aikit-config/scripts/attach.sh --preset frontend-team
```

Expected result:

- `CLAUDE.md`
- `.claude/commands/`
- `.claude/agents/`
- `.claude/.config-version`
- `.aikit/memory/`

## Start

```text
/aikit-bootstrap-project
```

Then verify:

```text
/aikit-doctor --scope install
```

## Work

Use `/implement-feature` for normal delivery. Use `/design-implement`, `/design-review` or `/security-check` only when the task clearly matches those routes.
