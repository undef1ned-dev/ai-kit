---
title: "Codex"
description: "Use AIKit through a Codex runtime workspace."
---

Use the Codex path when you want workspace-sync install and Codex command surfaces.

## Create A Workspace

```text
/aikit-runtime-workspace codex --preset frontend-team --workspace /tmp/aikit-codex
```

Expected result:

- `.aikit/runtime-entrypoints.json`
- `.aikit/runtime-tools.json`
- `.aikit/runtime-continuation-contract.md`
- `.codex/commands/`

## Inspect First

```text
/aikit-runtime-workspace codex --preset frontend-team --workspace /tmp/aikit-codex --dry-run
```

Use dry-run when you want to review planned writes before creating or updating a workspace.

## Verify

```text
/aikit-doctor --scope install
```

If Doctor reports a blocker, repair the install before starting task work.
