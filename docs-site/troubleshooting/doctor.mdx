---
title: "Doctor"
description: "Verify AIKit setup before starting task work."
---

Doctor checks whether AIKit is ready for use in the current repository or runtime workspace.

## Run Doctor

```text
/aikit-doctor --scope install
```

Expected result: `DOCTOR_REPORT` with install status, checked surfaces, evidence paths, one recommended repair command, one rerun command and stop conditions.

## Read The Result

Continue only when:

- install status is ready;
- expected command surfaces exist;
- bootstrap has no blockers;
- selected preset matches the project;
- the next task command is clear.

## When Doctor Fails

Use the recommended repair command in `DOCTOR_REPORT`. If the report points to install/update drift, inspect the plan:

```text
/aikit-install-update inspect --preset frontend-team --adapter codex
```

If the command surface or runtime workspace is stale, repair it:

Recommended repair command:

```text
/aikit-runtime-workspace codex --preset frontend-team --workspace /tmp/aikit-codex --operation update
```

Rerun command:

```text
/aikit-doctor --scope install
```

## Stop Conditions

Stop before implementation work if Doctor still reports a blocker after the repair command.
