---
title: "Recovery"
description: "Fix common AIKit setup failures."
---

Most setup failures are caused by an incomplete install, a wrong preset or a stale runtime workspace.

## Check Install State

```text
/aikit-doctor --scope install
```

If Doctor is blocked, do not start implementation work yet.

## Inspect The Install Plan

```text
/aikit-install-update inspect --preset frontend-team --adapter codex
```

## Recovery Loop

Recommended repair command:

```text
/aikit-runtime-workspace codex --preset frontend-team --workspace /tmp/aikit-codex --operation update
```

Rerun command:

```text
/aikit-doctor --scope install
```

## Common Fixes

| Symptom | Fix |
| --- | --- |
| Commands are missing | Re-run install or runtime workspace sync. |
| Wrong project type | Choose the preset that matches the repository. |
| Bootstrap warns about unsafe refs | Remove unsafe inputs and rerun bootstrap. |
| Runtime workspace is stale | Run the runtime workspace command with update mode. |

Rerun Doctor after each fix.

## Stop Conditions

If the same failure remains reproducible, open an issue with the `DOCTOR_REPORT` status and blocker names. Do not include secrets.
