title: "What Gets Installed"
description: "Files and directories AIKit writes during setup."
---

AIKit writes reviewable local files. It does not need live provider mutation for the normal install path.

| Path | Runtime | Purpose |
| --- | --- | --- |
| `CLAUDE.md` | Claude Code | Combined project instruction surface. |
| `.claude/commands/` | Claude Code | Slash commands generated from selected profiles and packs. |
| `.claude/agents/` | Claude Code | Runtime-visible specialist agents. |
| `.claude/.config-version` | Claude Code | Installed AIKit version marker. |
| `.aikit/memory/` | all runtimes | Reviewable local memory root. |
| `.claude/memory/` | Claude Code | Claude mirror of local memory. |
| `.aikit/runtime-entrypoints.json` | non-Claude | Runtime launcher surface. |
| `.aikit/runtime-tools.json` | non-Claude | Runtime tool registry. |
| `.aikit/runtime-continuation-contract.md` | non-Claude | Continuation rules for resumed runtime flows. |
| `.codex/commands/` | Codex | Workspace-local Codex command mirror. |
| `~/.codex/prompts` | Codex | Optional global prompt alias when Codex command sync is approved. |

Users should run commands. Backing scripts are implementation details for diagnostics and CI.

## Inspect Before Writing

Use dry-run style commands when you want to inspect a plan:

```text
/aikit-install-update inspect --preset frontend-team --adapter codex --json
/aikit-runtime-workspace codex --preset frontend-team --workspace /tmp/aikit-codex --dry-run
```

Expected result: a report describing planned writes and runtime entrypoints before you rely on the workspace.
