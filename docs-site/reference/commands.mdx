---

Start with commands, not with individual agents.

## First Run

```text
/aikit-bootstrap-project
/aikit-doctor --scope install
```

`/aikit-bootstrap-project` discovers the project and writes `BOOTSTRAP_REPORT`.

`/aikit-doctor --scope install` checks whether the install is ready for task work.

## Task Commands

| Command | Use when |
| --- | --- |
| `/implement-feature` | Normal implementation work. |
| `/design-implement` | Design is the primary input. |
| `/design-review` | The task is review-first and design-scoped. |
| `/security-check` | You need a security, secrets, auth or permissions review. |

## Runtime Commands

```text
/aikit-runtime-workspace codex --preset frontend-team --workspace /tmp/aikit-codex
/aikit-install-update inspect --preset frontend-team --adapter codex --json
```

Use runtime commands when evaluating Codex or OpenCode workspaces.
