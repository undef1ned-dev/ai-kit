Запусти агент `security-auditor` для аудита безопасности.

$ARGUMENTS

Агент должен:
1. Определить стек проекта (iOS / Django)
2. Проверить код на наличие секретов и конфиденциальных данных
3. Проверить OWASP Top 10 адаптированный под стек
4. Проверить зависимости на known vulnerabilities
5. Сформировать отчёт с приоритизированными findings

Если аргументы указывают на файлы — проверить только их.
Если не указаны — проверить изменения с последнего коммита.
Для полного аудита укажи: `/security-check полный аудит проекта`
