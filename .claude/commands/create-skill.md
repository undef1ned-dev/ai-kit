Запусти агент `skill-builder` для создания нового скилла.

$ARGUMENTS

Агент проведёт структурированное интервью по 4 фазам:

1. **Основы** — название команды, что делает, профиль, аргументы
2. **Оркестрация** — какие агенты, порядок выполнения, передача данных между ними
3. **Контекст** — предусловия, точки остановки, дополнительные файлы
4. **Результат** — создаваемые артефакты, финальный отчёт, следующие шаги

По завершении интервью агент покажет превью файла и запросит подтверждение перед записью.
