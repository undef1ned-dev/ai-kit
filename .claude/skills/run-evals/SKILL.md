Прогони эвалы AIKit скриптом `scripts/run-evals.py` из корня репозитория кита.

Аргументы пользователя: $ARGUMENTS

## 1. Что гонять

Эвалы разбиты на группы: `core` (ядро: скиллы base, хуки) и по группе на профиль (сейчас `vue-nuxt`). Список групп и объём прогона покажет `python3 scripts/run-evals.py --list`.

- В аргументах есть группа — гоняй только её: `/run-evals vue-nuxt` → `python3 scripts/run-evals.py vue-nuxt`. Несколько групп — через пробел. `all` — все группы.
- `changed` в аргументах → `--changed`: раннер сам найдёт группы, которые затронуты изменениями ветки и незакоммиченными правками. Правка `profiles/<профиль>/` — только этот профиль; правка `base/` или подготовки проекта — все группы.
- Группы нет — выполни `python3 scripts/run-evals.py --changed --list` и спроси пользователя, предложив варианты:
  - затронутые группы из вывода `--changed` (рекомендуй их, если там не всё);
  - конкретный профиль;
  - все группы.

  Заодно уточни режим, если он не назван: быстро (`--quick`: один прогон без базовой линии) или полно (3 прогона и сравнение с прогоном без плагина). Runtime по умолчанию — Claude Code; Codex (`--runtime codex`) или оба (`--runtime both`) — только если пользователь попросил.

## 2. Подтверждение

Покажи состав и объём: `python3 scripts/run-evals.py <группы> --list` с теми же фильтрами. Объём раннер печатает в долларах по прайсу API — объясни, что на подписке деньги не списываются, а тратятся лимиты, и доллары нужны для сравнения вариантов. Дождись согласия пользователя.

## 3. Прогон

Запусти `python3 scripts/run-evals.py <группы> <флаги>`. Прогон идёт минуты — запускай в фоне и дождись завершения.

## 4. Итог

- таблица: кейс, оценка, проваленные оценщики;
- для полного прогона — `Δ` против прогона без плагина: где кит помогает, где не даёт ничего;
- сколько ушло лимитов подписки — строка «Лимиты подписки» в конце вывода раннера (если её нет — вход по API-ключу, тогда назови оценку в долларах), и путь к отчёту `evals/results/<время>/`;
- что поправить в агентах и скиллах по проваленным оценщикам — предложи, но не меняй без согласия.

Не запускай эвалы сам по себе — только когда пользователь вызвал этот скилл.
