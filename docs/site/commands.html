Команды

Все скиллы ядра — они есть в любом проекте с AIKit, какие бы профили ни стояли. Скиллы профилей и паков описаны в каталоге.

#Как вызывать

RuntimeЯвный вызовСписок скилловАвтовызов
Claude Code/implement-feature <задача>набери /да, по description скилла
Codex$implement-feature <задача>/skillsда
OpenCodeназови скилл в сообщении—да

Если кит стоит плагинами, у скилла есть и имя с префиксом плагина: /aikit:implement-feature, /vue-nuxt:new-page. Короткое /implement-feature работает, пока имя не занято другим скиллом.

Автовызов значит, что runtime сам запустит скилл, если задача подходит под его описание. Например, на «реализуй страницу заказов» может сработать /implement-feature. Скиллы с пометкой «только явный вызов» сами не запускаются: у них есть побочные эффекты (пишут память, ведут длинный диалог).

#Панель AIKit Deck

Только Claude Code с установкой плагинами: панель — мод плагина ядра aikit. В проекте с .aikit/profiles.json она открывается сама, иначе — командой /deck.

Что в панелиКак работает
Кнопки командБазовые команды кита по группам, ниже — команды профилей и паков проекта. Команде с аргументом открывается поле ввода (подсказка — argument-hint скилла), флаги вроде --tdd — переключатели. Обязательное поле пустым не отправится
Режим«Отправить» (по умолчанию) — команда сразу уходит в сессию; «Вставить» — попадает в поле ввода, Enter жмёшь сам. Клавиша m
СубагентыВсе субагенты сессии — запущенные из чата, скиллом или панелью: тип, задача, время, статус. Список даёт сам Claude Code
СправкаВкладка 2: все команды с аргументами, описанием и примером, поиск по имени и описанию
ИсторияПоследние запуски из панели и команды кита, набранные в чате. Строка истории открывает команду снова с тем же текстом
ПамятьРазмер .aikit/memory/INDEX.md в шапке; больше 50 строк из 60 — строка «пора /optimize-memory» под полем ввода, даже при закрытой панели

Панель не вызывает модель: кнопки, справка, субагенты и память — локальные файлы и данные Claude Code. Лимиты тратит только запущенная команда — ровно как набранная вручную.

#Разработка

КомандаЧто делаетАгенты
/implement-featureРеализует фичу цепочкой агентов профиля: архитектор → кодер → тестировщик и ревьюер параллельно → проверка lint/test, исправления и проверка в работе. Флаги: --tdd — сначала падающие тесты, --worktree — работа в отдельном git worktreeагенты профиля по ролям
/fix-bugЧинит баг: воспроизведение → тест, который ловит баг → минимальный фикс → lint, test и ревьюагенты профиля по ролям
/check-featureЗапускает приложение командой run и проходит сценарий фичи: в браузере для UI, запросами для API; сообщает, работает ли—
/workflowВизард: определяет тип задачи, строит цепочку агентов, ведёт по шагам. Только явный вызовworkflow-runner

#Анализ и планирование

КомандаЧто делаетАгенты
/analyze-mvpРазбирает идею фичи: интервью, варианты, бизнес-кейс, риски, RICE; результат — документ в docs/mvp/mvp-analyst
/implement-mvpПревращает MVP-документ в технический план: API-контракт, scope по частям системы, порядок работtech-planner
/cross-checkЧто поменять на другой стороне, если меняется API или формат данныхcross-project-analyst

#Качество и безопасность

КомандаЧто делаетАгенты
/security-checkАудит безопасности: OWASP Top 10, секреты в коде и конфигах, авторизация, инъекцииsecurity-auditor
/coverage-checkЗапускает тесты с покрытием, находит критичные модули без тестов и предлагает тест-кейсыquality-специалист профиля (specialists.quality)
/tech-debtАудит технического долга: большие модули, дублирование, нарушения слоёв, TODO; backlog P1/P2/P3quality-специалист профиля (specialists.quality)
/write-ui-textsПишет или проверяет тексты интерфейса: кнопки, ошибки, пустые состояния, онбордингux-writer

#Память проекта

КомандаЧто делаетАгенты
/capture-memoryЗаписывает решения, паттерны и поправки агентам после задачи в .aikit/memory/. Только явный вызовmemory-writer
/memory-statusПоказывает, что накоплено в памяти и не пора ли её сжать—
/optimize-memoryСжимает индекс памяти, объединяет дубли, убирает устаревшее; переносит решения из логов задач прежних версий. Только явный вызовmemory-optimizer

#Расширение кита

КомандаЧто делаетАгенты
/create-agentСоздаёт нового агента через интервью из 6 фазagent-builder
/create-skillСоздаёт новый скилл через интервью из 4 фазskill-builder
/improve-aikitРазвивает сам репозиторий AIKit. Только явный вызовaikit-maintainer
/aikit:setupПодключает проект к киту, установленному плагинами: профили и паки, блок правил, .aikit/profiles.json, память, настройки. Есть только в плагине ядра—

#Работают сами

СкиллЧто делает
git-commitСообщения коммитов по Conventional Commits, без Co-Authored-By и приписок «Generated with»
git-branchИмена веток по Conventional Branch: feat/…, fix/…, chore/…

Их не нужно вызывать: runtime применяет их каждый раз, когда создаёт коммит или ветку.
