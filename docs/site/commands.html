Команды

Все скиллы ядра — они есть в любом проекте с AIKit, какие бы профили ни стояли. Скиллы профилей и паков описаны в каталоге.

#Как вызывать

RuntimeЯвный вызовСписок скилловАвтовызов
Claude Code/implement-feature <задача>набери /да, по description скилла
Codex$implement-feature <задача>/skillsда
OpenCodeназови скилл в сообщении—да

Автовызов значит, что runtime сам запустит скилл, если задача подходит под его описание. Например, на «реализуй страницу заказов» может сработать /implement-feature. Скиллы с пометкой «только явный вызов» сами не запускаются: у них есть побочные эффекты (пишут память, ведут длинный диалог).

#Разработка

КомандаЧто делаетАгенты
/implement-featureРеализует фичу цепочкой агентов профиля: архитектор → кодер → тестировщик и ревьюер, затем проверка lint/testагенты профиля по ролям
/workflowВизард: определяет тип задачи, строит цепочку агентов, ведёт по шагам. Только явный вызовworkflow-runner

#Анализ и планирование

КомандаЧто делаетАгенты
/analyze-mvpРазбирает идею фичи: интервью, варианты, бизнес-кейс, риски, RICE; результат — документ в docs/mvp/mvp-analyst
/implement-mvpПревращает MVP-документ в технический план: API-контракт, scope по частям системы, порядок работtech-planner
/cross-checkЧто поменять на другой стороне, если меняется API или формат данныхcross-project-analyst

#Качество и безопасность

КомандаЧто делаетАгенты
/security-checkАудит безопасности: OWASP Top 10, секреты в коде и конфигах, авторизация, инъекцииsecurity-auditor
/write-ui-textsПишет или проверяет тексты интерфейса: кнопки, ошибки, пустые состояния, онбордингux-writer

#Память проекта

КомандаЧто делаетАгенты
/capture-memoryЗаписывает решения, паттерны и поправки агентам после задачи в .aikit/memory/. Только явный вызовmemory-writer
/memory-statusПоказывает, что накоплено в памяти и не пора ли её сжать—
/optimize-memoryАрхивирует старые задачи и сжимает индекс памяти. Только явный вызовmemory-optimizer

#Расширение кита

КомандаЧто делаетАгенты
/create-agentСоздаёт нового агента через интервью из 6 фазagent-builder
/create-skillСоздаёт новый скилл через интервью из 4 фазskill-builder
/improve-aikitРазвивает сам репозиторий AIKit. Только явный вызовaikit-maintainer

#Работают сами

СкиллЧто делает
git-commitСообщения коммитов по Conventional Commits, без Co-Authored-By и приписок «Generated with»
git-branchИмена веток по Conventional Branch: feat/…, fix/…, chore/…

Их не нужно вызывать: runtime применяет их каждый раз, когда создаёт коммит или ветку.
