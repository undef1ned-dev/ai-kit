## Работа в Claude Code

- Правила проекта — `CLAUDE.md`. Скиллы вызывай через `/name` или по описанию. В плагине доступно имя `/плагин:name`; аргументы передаются после имени скилла.
- При установке через `attach.sh` скиллы находятся в `.claude/skills/`, агенты — в `.claude/agents/`. Их вызывай без префикса плагина.
- При установке плагинами агенты кита доступны с префиксом: `aikit:<агент>` для ядра, `<профиль|пак>:<агент>` для профилей и паков. Имена ролей из `.aikit/profiles.json` дополняй именем плагина только для агентов, поставленных этим плагином.
- Локальные агенты проекта, включая `aikit-maintainer` в репозитории кита, запускаются без префикса.
- Модели агентов: если в `.aikit/models.json` есть переопределение, используй его уровень (`opus`, `sonnet`, `haiku`) или поле `claude` объекта по runtime. Для агента плагина передай модель при запуске; для локального агента применяй настройки через `scripts/agent_models.py apply --runtime claude` из кита. Без переопределения используй настройки определения агента.
- Хуки и разрешения — `.claude/settings.json` или настройки плагина. Проверяй подключение через `/hooks` и отметки `aikit_hook.py --status`.
- Контракты профилей — `.aikit/profiles.json`, командная память — `.aikit/memory/`.
