В Claude Code возьми корень установленного плагина из `${CLAUDE_PLUGIN_ROOT}`. В Antigravity найди корень установленного ядра по предку этого SKILL.md с файлами `scripts/plugin-init.py` и `scripts/project-updates.json`. Запусти из корня проекта:

```bash
python3 "<корень плагина>/scripts/plugin-init.py" --runtime <claude|antigravity> --update --workspace .
```

В Codex используй нативный скилл. Для установки адаптером используется отдельное обновление адаптера.

Если пользователь передал `--dry-run`, добавь этот флаг и покажи план. В обычном режиме примени изменения. Скрипт сам определяет установленный набор и версию проекта. Передай результат скрипта, включая версию, действия и изменённые файлы. При ошибке передай её причину, без повторного запуска установки и вопросов о выборе профиля. Если исходник плагина устарел, обновление общего кэша выполняется отдельно, затем нужна новая сессия.
