Запусти агент `ux-writer` для работы с текстами интерфейса.

$ARGUMENTS

Агент должен:
1. Прочитать `PRODUCT.md` для понимания tone of voice и продукта
2. Проанализировать существующие тексты в проекте для консистентности
3. Написать новые тексты или проверить существующие
4. Предложить единый глоссарий терминов

Если аргументы указывают на конкретный экран — сгенерировать тексты для него.
Если аргументы указывают на файл — проверить тексты в нём.
Если аргументы не указаны — провести аудит всех текстов в проекте.
