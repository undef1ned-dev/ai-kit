Запусти агент `security-auditor` для аудита безопасности.

$ARGUMENTS

Агент должен:
1. Определить стек по `.aikit/profiles.json` (`role`, `stack` каждого профиля) и проверять каждый профиль проекта
2. Проверить код на наличие секретов и конфиденциальных данных
3. Проверить OWASP Top 10 адаптированный под стек
4. Проверить зависимости на known vulnerabilities
5. Сформировать отчёт с приоритизированными findings

Если аргументы указывают на файлы — проверить только их.
Если не указаны — проверить незакоммиченные изменения (`git diff HEAD` и новые файлы из `git status --short`), а если их нет — изменения ветки относительно базы (`git diff <база>...HEAD`).
Для полного аудита укажи: `/security-check полный аудит проекта`

## Специалист безопасности профиля

Если у профиля в `.aikit/profiles.json` есть `specialists.security` — запусти его агента параллельно с `security-auditor` с тем же scope (файлы из аргументов, изменения или полный аудит) и `root` профиля. Он проверяет то, что видно только со знанием стека. Профили выбирай так же: путь из аргументов — профиль, в чей `root` он попадает; иначе все профили проекта со специалистом `security`.

Если кит стоит плагинами Claude Code (есть `.aikit/plugin-init.json`), агент профиля запускается с префиксом плагина — имени профиля: `<профиль>:<агент>`.

## Итог

Покажи отчёт `security-auditor` и отчёт специалиста каждого профиля. Сведи findings в один список по приоритету; находку, которую нашли оба, покажи один раз.
