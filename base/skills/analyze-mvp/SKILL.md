Запусти агент `mvp-analyst` для анализа следующей идеи:

$ARGUMENTS

Агент проведёт полный анализ:
1. Загрузит контекст из `PRODUCT.md` и `docs/mvp/` (ранее проанализированные фичи)
2. Задаст структурированные вопросы для понимания бизнес-цели, источника проблемы и сегмента
3. Спросит сколько вариантов продуктового подхода рассмотреть (1-3) и предложит их на выбор — каждый с разным scope, сегментом и бизнес-ставкой
4. Проанализирует выбранный вариант по осям: стратегическое соответствие, бизнес-кейс, конкурентный контекст, импакт на существующих пользователях, технический импакт, риски, rollout-стратегия, операционная готовность
5. Рассчитает RICE score для приоритизации
6. Создаст документ `docs/mvp/{название}.md` по расширенному шаблону (с секцией альтернативных подходов)
7. Вернёт структурированное резюме с рекомендацией и обоснованием

Если `PRODUCT.md` отсутствует или не заполнен — запросит ключевой контекст о продукте прежде чем начинать анализ.
