Запусти агент `agent-builder` для создания нового агента.

$ARGUMENTS

Агент проведёт структурированное интервью по 6 фазам:

1. **Идентичность** — имя, роль, профиль, модель
2. **Инструменты** — какие tools нужны, какие файлы читать, нужны ли MCP-серверы
3. **Алгоритм** — шаги работы, уточняющие вопросы, шаблоны
4. **Правила качества** — must-have, запрещено, самопроверка
5. **Формат вывода** — что создаёт агент, структурированный блок, отчёт
6. **Интеграция** — кто вызывает, цепочка агентов, нужен ли скилл

По завершении интервью агент покажет превью файла и запросит подтверждение перед записью.
