Запусти агент `workflow-runner` для следующей задачи:

$ARGUMENTS

Агент автоматически:
1. Прочитает контракты профилей в `.aikit/profiles.json` и манифесты агентов runtime
2. Сопоставит задачу с профилями по `path_signals`, `role` и `stack`
3. Определит тип задачи (реализация / анализ / проверка / DevOps / AI)
4. Построит цепочку из агентов профиля по ролям и специалистов из контракта
5. Покажет план и запросит подтверждение
6. Выполнит каждый шаг с передачей контекста между агентами
7. Сформирует итоговый рапорт

Если runtime дополнительно подхватывает `/workflow` как slash-команду — можно использовать её как alias.
Но canonical path для Codex — это skill `workflow` и агент `workflow-runner`, а не обязательный slash discovery.

Если задача не указана — агент проведёт интервью чтобы уточнить что нужно сделать.
