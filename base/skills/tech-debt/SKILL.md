Оцени технический долг силами quality-специалиста профиля.

$ARGUMENTS

## Шаг 0 — Профиль

Прочитай `.aikit/profiles.json`. Если файла нет — проект не подключён к AIKit: предложи `/aikit:setup` и остановись.

Выбери профили для проверки: если в аргументах есть путь — профиль, в чей `root` он попадает; иначе все профили проекта, по очереди.

## Шаг 1 — Анализ

Для каждого выбранного профиля возьми агента из `specialists.quality.agent` и запусти его с задачей:
1. Найти слишком большие модули, классы и функции
2. Найти дублирующийся код
3. Проверить соблюдение архитектурных слоёв из `CLAUDE.md` профиля
4. Найти TODO/FIXME/HACK
5. Сформировать приоритизированный список P1/P2/P3 с конкретными рекомендациями

Передай агенту путь из аргументов, если он есть.

Если у профиля нет `specialists.quality` — сделай анализ сам по правилам и слоям из `CLAUDE.md`.

## Шаг 2 — Итог

Покажи QUALITY_REPORT каждого профиля и общий backlog по приоритетам. Код не меняй без согласия пользователя.
