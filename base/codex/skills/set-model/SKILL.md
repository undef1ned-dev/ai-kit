## Исполнение в Codex

Задачу и флаги бери из текущего сообщения пользователя. Прочитай `AGENTS.md`, `PRODUCT.md` и `.aikit/profiles.json`, если они относятся к задаче. Для команд профиля используй его `root` и переопределённые `commands`, а не команды, выбранные по названию стека. Пользовательские инструкции имеют приоритет над рекомендациями скилла.

Если шаг требует субагента, используй локальное имя из `.codex/agents/*.toml` без префикса плагина. Предпочитай загруженную именованную роль. Если инструмент не умеет выбирать роль, передай доступному субагенту её `developer_instructions` и нужный контекст; передавай настройки модели только когда это поддерживается схемой инструмента. Не утверждай, что модель из TOML применена, если выбранный способ запуска её не применяет. Если инструменты делегирования недоступны, останови цепочку с объяснением, а не выдавай работу основного потока за запуск агентов.

Независимых тестировщика и ревьюера запускай до ожидания любого из них, затем дождись обоих; исправления передавай уже запущенному агенту доступным инструментом продолжения, если он есть. Лимит параллельности соблюдай. Не создавай пользовательские чаты вместо субагентов. Ключи и параметры запуска инструментов бери из фактической схемы текущей сессии.

Вопросы пользователю задаёт основной поток, а не субагент. Неполный или прерванный результат агента не считай успехом. Модель сама по себе не заменяет запуск проверок: в итог включай реально выполненные команды и их результаты. Операции git выполняй по скиллам `git-branch` и `git-commit`, учитывая режим команды и прямые указания пользователя.

Покажи или измени модель агента Codex. Используй native defaults из TOML, без чтения инструкций другого runtime.

Найди scripts/agent_models.py, поднимаясь от расположения этого SKILL.md к предкам. При установке адаптером используй .aikit/scripts/agent_models.py. Не угадывай фиксированное число уровней. Нужен рабочий Python 3.11+; на Windows проверь интерпретатор, не используй Python 2 или заглушку Store.

Без аргументов выполни:
python3 "<корень>/scripts/agent_models.py" show --runtime codex --workspace .
Покажи нативную модель/усилие, переопределение проекта и итог. У адаптера корень — .aikit.

При изменении проверь имя по .codex/agents/*.toml и .aikit/profiles.json. Получи точный id модели и при необходимости усилие; не угадывай id. Уровни opus/sonnet/haiku принимаются лишь как совместимые алиасы из adapters/models.json. Если есть сомнения в доступности модели, проверь официальный источник и сообщи неопределённость.

Прочитай .aikit/models.json, сохрани остальные поля и runtime. Для конкретной модели обнови только agents.<имя>.codex; строковый прежний уровень преобразуй в объект с ключами claude и opencode, сохранив прежний уровень для них. Значение codex — строка id (усилие берётся из нативного TOML). Совместимый уровень без указания runtime действует на все runtime — явно объясни это до записи.

Выполни apply --runtime codex --workspace . тем же скриптом; проверь show. Обновление кита повторно применяет проектные настройки. Не утверждай, что активный субагент уже сменил модель: открой новую сессию Codex. В отчёте укажи агента, до/после, усилие, изменённые файлы и результат apply. Коммит — по режиму команды и авторизации пользователя.
