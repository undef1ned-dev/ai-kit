---

От этого SKILL.md поднимись до корня установленного плагина с файлами `scripts/plugin-init.py` и `scripts/project-updates.json`. Из корня проекта запусти Python 3.11+:

```bash
python3 "<корень плагина>/scripts/plugin-init.py" --runtime codex --update --workspace .
```

На Windows используй рабочий интерпретатор Python 3.11+, при необходимости полный путь или `py -3`. Если пользователь передал `--dry-run`, добавь этот флаг и покажи план. В обычном режиме примени изменения. Скрипт сам определяет установленный набор и версию проекта. Передай результат скрипта, включая версию, действия и изменённые файлы. При ошибке передай её причину, без повторного запуска установки и вопросов о выборе профиля.

Для обновления общего кэша отдельно используется `codex plugin marketplace upgrade aikit`, после него открой новую сессию. Если скрипт изменил проектное включение или агентов, сообщи, что эти изменения применятся в новой сессии Codex.
