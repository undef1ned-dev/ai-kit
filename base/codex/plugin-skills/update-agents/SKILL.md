## Исполнение в Codex

Задачу и флаги бери из текущего сообщения пользователя. Прочитай `AGENTS.md`, `PRODUCT.md` и `.aikit/profiles.json`, если они относятся к задаче. Для команд профиля используй его `root` и переопределённые `commands`, а не команды, выбранные по названию стека. Пользовательские инструкции имеют приоритет над рекомендациями скилла.

Если шаг требует субагента, используй локальное имя из `.codex/agents/*.toml` без префикса плагина. Предпочитай загруженную именованную роль. Если инструмент не умеет выбирать роль, передай доступному субагенту её `developer_instructions` и нужный контекст; передавай настройки модели только когда это поддерживается схемой инструмента. Не утверждай, что модель из TOML применена, если выбранный способ запуска её не применяет. Если инструменты делегирования недоступны, останови цепочку с объяснением, а не выдавай работу основного потока за запуск агентов.

Независимых тестировщика и ревьюера запускай до ожидания любого из них, затем дождись обоих; исправления передавай уже запущенному агенту доступным инструментом продолжения, если он есть. Лимит параллельности соблюдай. Не создавай пользовательские чаты вместо субагентов. Ключи и параметры запуска инструментов бери из фактической схемы текущей сессии.

Вопросы пользователю задаёт основной поток, а не субагент. Неполный или прерванный результат агента не считай успехом. Модель сама по себе не заменяет запуск проверок: в итог включай реально выполненные команды и их результаты. Операции git выполняй по скиллам `git-branch` и `git-commit`, учитывая режим команды и прямые указания пользователя.

Обнови агентов AIKit в Codex. Плагины Codex агентов не поставляют, поэтому после обновления плагина `.codex/agents/*.toml` остаются прежними, пока их не пересоберёт скрипт кита. Флаг `--with-plugins` объединяет обновление плагинов и агентов; без флага сохраняется прежний режим. Полное подключение проекта — скилл `setup`.

## 1. Проверь, что нужно

- Нужен `.aikit/plugin-init.json` с Codex в `runtimes`: из него берутся профили и паки. Если файла нет, проект не подключён — предложи `$aikit:setup` и остановись.

## 2. Найди корень плагина

Поднимайся от этого SKILL.md к предкам до scripts/plugin-init.py и base/codex. Проверь найденный корень; фиксированное число уровней не используй.

Если пользователь передал `--with-plugins`, перейди к следующему разделу. Без флага: если плагин ещё не обновлён, агенты соберутся из старой версии кита. Предложи единый режим `update-agents --with-plugins` или ручное обновление `codex plugin marketplace upgrade aikit` с новой сессией; без такого запроса маркетплейс сам не обновляй.

## Единое обновление — --with-plugins

Явный вызов с флагом разрешает обновление маркетплейса `aikit`: это затронет установленные из него плагины на машине. Другие маркетплейсы скрипт не обновляет. Нужен Python 3.11+ для проверки TOML и Codex CLI с `plugin list --json`.

```bash
python3 "<корень>/scripts/update-codex-plugins.py" --workspace .
```

На Windows выбери доступный Python 3.11+ (`py -3` или полный путь), а не Python 2 или заглушку Store. Скрипт проверяет подключённые профили и паки, выполняет `codex plugin marketplace upgrade aikit`, читает свежий источник из `codex plugin list --marketplace aikit --json` и запускает его `scripts/plugin-init.py` во временном проекте. Использовать для пересборки старый `<корень>` после обновления нельзя.

Только после проверки версий и TOML он заменяет управляемые агенты проекта; свои агенты, правила, контракты, память и модели команды сохраняет. Сбой пересборки оставляет прежних агентов, сбой записи откатывает записанные файлы. Обновлённый маркетплейс при ошибке не откатывается. Версия пересборки записывается в `.aikit/plugin-init.json`.

Покажи версии до и после из вывода скрипта. Скажи открыть новую сессию Codex и при изменении хуков повторно одобрить их в `/hooks`. Ошибку передай пользователю; после неё не запускай обычную пересборку из старого корня. На этом режим `--with-plugins` завершён.

## 3. Запусти обновление

```bash
python3 "<корень>/scripts/plugin-init.py" --runtime codex --refresh-agents
```

На Windows без `python3` — `python` или `py -3`. Скрипт берёт профили и паки прошлого запуска, пересобирает агентов кита в `.codex/agents/*.toml` и применяет модели: нативные defaults из TOML и переопределения проекта из `.aikit/models.json`. Свои агенты команды в `.codex/agents/`, правила в `AGENTS.md`, `.aikit/profiles.json`, память и настройки он не трогает; агенты профилей и паков, которых больше нет в ките, удаляет.

## 4. Отчёт

Покажи, что напечатал скрипт, и итоговые модели:

```bash
python3 "<корень>/scripts/agent_models.py" show --runtime codex --workspace .
```

Если нужно сменить набор профилей или паков, обновить правила в `AGENTS.md` или контракты, — это `$aikit:setup`. Новые агенты подхватятся в новой сессии Codex; проект должен быть доверенным.
